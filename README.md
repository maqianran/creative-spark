# Creative Spark: A Creative Prompt Generator

Creative Spark is a small interactive website that helps students and content creators turn a vague idea into a concrete, time-boxed creative task.

## Project idea

- **Intended users:** Students and creators who want to make a short video, a photography exercise, or a poster but need a starting point.
- **Main interaction:** Choose a creative format, a mood, and a time budget. The website selects a task from its built-in prompt library.
- **Feedback:** The result card shows a task, a short summary of the choices, a time limit, and a suggested next action. Users can draw another card, copy the task, or reset the form.
- **Error handling:** The page explains which choices are missing instead of generating an empty result. It also shows a fallback message if clipboard access is unavailable.

## How to run

This project uses plain HTML, CSS, and JavaScript. It has no third-party package dependencies, API keys, or backend service.

### Option A: Open the page directly

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Choose a format, a mood, and a time budget, then generate a prompt.

### Option B: Run a local static server (recommended)

Open a terminal in the project folder and run:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/` in your browser. Press `Control+C` in the terminal to stop the server.

Python is only used to serve the static files locally. The website itself is implemented in HTML, CSS, and JavaScript.

## Known limitations

- Tasks are selected from a small built-in library rather than generated by a live AI model.
- The first version has three creative formats, three moods, and three time budgets.
- The page does not use a database or save the user's selections after a reload.
- Clipboard behaviour may vary by browser and permissions.

## Testing checklist

- [ ] Try to generate a task without completing the required choices.
- [ ] Select all required options and generate a task.
- [ ] Draw another card and confirm that the task changes.
- [ ] Copy a task and paste it into a text editor.
- [ ] Reset the page and check that the selections and result are cleared.
- [ ] Test at a narrow/mobile viewport.
- [ ] Ask at least one person to try the experience before explaining it, then record the observation and decision in `PROCESS.md`.

## Use of AI tools

ChatGPT was used to help interpret the brief, plan the interaction, draft and explain code, and review likely edge cases. The project author should run the code, understand the main interaction, and record the actual tests and decisions before submission.
